🔑 How to get your Session Hash

  1. Make sure you are logged into my.etmsolutionsusa.com
  2. Press F12 → click the Network tab at the top
  3. In the filter bar, type tracker/list
  4. Press F5 to reload the page — a request named list will appear
  5. Click on list → click Payload on the right panel
  6. Copy the long value next to hash → paste it in the Run Check tab
